## About Me

기업 업무 프로세스를 분석하고 자동화하는 일을 해왔습니다.

제가 가장 강점을 갖는 부분은 단순히 코드를 구현하는 것보다,
**복잡한 업무를 빠르게 이해하고 절차와 예외를 구조화한 뒤 운영 가능한 시스템으로 만드는 과정**입니다.

자동화가 실제 현업에서 오래 동작하려면 기능 구현뿐 아니라
**로그, 예외 처리, 재시도, 복구, 유지보수성**까지 함께 설계되어야 한다고 생각합니다.

최근에는 이러한 경험을 RPA에만 한정하지 않고
**Python / FastAPI 기반 Backend**, **AI Agent**, **VLM 기반 문서 처리**, **Intelligent Workflow**로 확장하고 있습니다.

## Strengths

- **업무 분석** — 실제 업무 흐름과 요구사항을 빠르게 파악하고 구조화
- **Workflow 설계** — 정상 흐름뿐 아니라 예외·분기·재처리까지 고려한 절차 설계
- **Automation Engineering** — 로그, 오류 처리, 복구 가능성을 고려한 안정적인 자동화
- **문서화와 설계** — 구현 전에 요구사항과 실행 흐름을 명확하게 정리
- **AI 활용 개발** — 설계와 검증에 집중하고 AI를 구현 생산성을 높이는 도구로 활용
